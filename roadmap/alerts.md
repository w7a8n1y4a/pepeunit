# Уведомления

Список и меню типов собраны. Раздел скрыт при `pu_ff_notification_enable == false`.

## Список

`/alerts?scope=` открывается на тике 3. Тик ходит от 1 до 5. Когда на тике 5 карточки всё ещё не влезают, список листается. Без входа — сота ошибки «Нет входа».

Фильтр: к прочтению, прочитанные, все. По умолчанию к прочтению. Там же «Прочитать все» и окно страницы. Сота «Видимые типы» ведёт на `/alerts/types`.

Карточка: тип сверху слева, `small_text` в центре, прочитана или нет снизу слева, время `MM.DD HH:MM` в поясе клиента снизу. Тап открывает таблицу `table_text`. Если есть `big_text`, вместо таблицы открывается лог. Непрочитанное помечается прочитанным при открытии. У обоих окон есть копирование.

Пока есть вход и флаг уведомлений, клиент держит `GET /notifications/stream`. Новое событие увеличивает бейдж и общее число. Если оно проходит текущий фильтр и открыта первая страница, карточка встаёт в начало списка.

На home сота показывает `Всего N шт.`. Непрочитанные — красный кружок с числом на стыке верхней правой и правой граней, больше 99 пишется как `99+`.

## Типы

`/alerts/types` — по соте на тип, который может получить текущая роль. Тап включает или выключает тип в запросе списка. Пока меню не трогали, включены все доступные.

User получает сводки, DataPipe и задачи репозитория или прошивки, которые запускает сам. Admin добавляет команды инстанса. Owner добавляет перезапуск. Имена типов на сотах — как в API.
