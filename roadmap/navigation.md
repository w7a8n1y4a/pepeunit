# Навигация

- **К родителю сущности** (план) — цепочка UnitIO → Unit → Repo; иконка в духе `house.svg`
- Web: адресная строка совпадает с открытым экраном. `push` и `replace` пишут путь, `pop` остаётся возвратом. `scope` в query у поиска пиров и пользователей, списков allow/deny, репозиториев, веток, уведомлений и аппаратов. Текст фильтров в URL не пишется
- Репозиторий открывается по `/registry/repo/:uuid`. Аппарат — по `/units/:uuid`, узел — по `/units/:uuid/io/:io`

Меню — дерево, которое выводит к действию. Может быть встроено в экран.

## Типы экранов

Инфокарточка · поиск · форма · клавиатура кнопок · редактор yml · Grafana kiosk · графики · комбинированные · кастомные (в той же сотовой стилистике).
