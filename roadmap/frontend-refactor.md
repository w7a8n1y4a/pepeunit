# Рефактор фронтенда в клиент

Клиент — Flutter-приложение в этом репозитории. Ограничения UI лежат в коде и в `.cursor/rules/` (`client.mdc`, `hive-ui.mdc`, `hex-layout.mdc`, `hex-scale.mdc`). Здесь только то, что ещё предстоит сделать. Реализованное описано в коде и правилах.

## Library

- Структура устроена таким образом, чтобы поддерживать ru/en и в будущем возможность добавить другие языки
- в соте - /people/settings Приложение, у пользователя появлятся ещё одна настройка, отвечающая за режим отображения md файлов. Либо рендер либо raw. Пусть выбор языка будет слева по центру, а режима raw справа по центру

Рендер md:
1. Поддержка базовой структуры языка
2. Поддержка mermaid
3. Поддержка вставки картинок
4. Поддержка :::danger ::: синтаксиса для рендера важных моментов. конечно же для warning tip и тд пусть то же работает

## Обновления

- Бинарники и md-инструкция в ассетах релизов GitLab/GitHub
- Клиент сравнивает версию с релизами и предлагает обновление
- Web: owner — плашка обновления сервера; остальные — обновления клиента
- Текст инструкции — в Settings / About с бейджем на соте
