# Комбинированные интерфейсы

Эталон сложности — карточка Unit. Старый фронт вываливал всё сразу (версии, RAM/flash/сеть, env, архивы, бинарники, MQTT, логи, опции, удаление) — антипаттерн. Лёгкая асимметрия сот показывает иерархию.

Идеи:

- MQTT: одна кнопка → диагональная панель из 6 сот (5 команд + назад), лёгкое затемнение фона
- key–value «ёлочкой»: key ~−135° к левой нормали, value ~−45° к правой — протестировать
