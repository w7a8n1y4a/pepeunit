# Аккаунт и сеть

Реализовано (`/people`, `/people/login|register|settings`):

- регистрация / вход по ключу, выход, скачивание ключа
- настройки: логин, аватар, sync профиля в сеть, язык, UTC-пояс
- vault глобального аккаунта + сессии инстансов
- сота ошибки с копированием текста (`ErrorCell`)

Сеть / инстансы (`/peers/…`):

- портрет текущего инстанса, список известных, поиск, allow/deny, ручное добавление
- карточка инстанса: target, relogin, метрики, настройки owner и т.д. по ролям и ff
