# Аккаунт и сеть

Аккаунт и сеть собраны. Остальные разделы меню — заглушки, см. [sections.md](sections.md).

## Аккаунт

`/people`, `/people/login`, `/people/register`, `/people/settings`, `/people/settings/alerts`.

Без ключа: вход и регистрация. С ключом: профиль (логин, аватар, отпечаток), настройки, скачивание ключа, выход.

Настройки:

- аватар: выбор файла и drop, PNG фиксированной стороны
- логин пишется сразу
- отправка профиля в избранный инстанс, кулдаун 1 мин
- вытягивание аватара, логина и уведомлений из избранного инстанса
- язык и UTC-пояс — только клиент
- уведомления: сводки, время UTC, DataPipe, Telegram; уходят вместе с профилем

Vault хранит глобальный аккаунт и сессии инстансов. Ошибка — сота с копированием текста.

На home сота Аккаунта показывает логин, отпечаток и аватар.

## Сеть

`/peers` и вложенные маршруты.

Корень: избранный инстанс или «Найди инстанс», затем поиск. Та же марка инстанса стоит на home.

Поиск (`/peers/search?scope=0|1|2`): фильтр по хосту; у Admin и Owner в той же соте статусы доверия. Карточки с пингом и версией, масштаб и листание, когда сот не хватает. Настройки поиска: белый и чёрный списки (`/peers/allow`, `/peers/deny`, тот же `scope`) и локальное добавление (`/peers/add`) — чтение `/instances/current`, без пира на бэкенде.

Карточка (`/peers/instance?url=`), состав по роли и флагам:

- сводка листами: метрики, инфо, флаги; копирование ссылки
- избранный: повторный вход по соте инстанса; Owner — управление; любой вошедший — пользователи; разжаловать
- чужой: сделать избранным; Admin и Owner — модерация (доверить, блокировать, удалить; опрос, если федерация включена)
- Telegram-бот, если флаг включён: ссылка верификации или публичная ссылка бота без ключа

Управление избранным (`/peers/tune`), только Owner. Два входа: настройки и команды.

Настройки (`/peers/tune/settings`): инстанс, MQTT, DataPipe, уведомления, Telegram, аватар инстанса. Инстанс дробится дальше: флаги, базовые, лимиты пользователей, реестр, устройства, GitHub, логи, контакты. MQTT — базовые и клиенты. DataPipe — базовые и соединение. Уведомления — базовые и Telegram-бот. Telegram — подключение и внешний вид. Дочерний экран закрыт, пока выключен его флаг. Число, enum и текст проверяются до отправки; на подключении Telegram флаг бота включается только когда остальные поля валидны.

Команды (`/peers/tune/ops`): тесты, опрос соседей (при федерации), отслеживание (`/peers/track` — пир на бэкенде), перезапуск. Отслеживание и перезапуск — только Owner.

Пользователи избранного (`/peers/users`, `?scope=1|2`). Ручка `GET /users` открыта любому вошедшему; без сессии соты нет. Две соты фильтров, дальше карточки. Поиск по логину, роли User / Admin / Owner (по умолчанию все), статусы Active / Blocked (по умолчанию только активные), порядок по дате создания (по умолчанию новые ближе к центру). Масштаб: два круга — 16 карточек, третий круг — ещё 18. Страница — стрелки и диапазон `1-16 из count`. Карточка: аватар или `account.svg`, логин сверху слева, отпечаток ключа `6-6` снизу по центру, роль вдоль правого ребра, снизу вверх. Заблокированные — красная рамка.

Внутри карточки (`/peers/users/member`): повтор карточки. Назначить или снять админа может только Owner, и не у владельца. Блокировка и разблокировка — Admin и Owner. Обычный User только смотрит.
