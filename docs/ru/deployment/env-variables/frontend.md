# Frontend

[Frontend](/deployment/dependencies/frontend) - готовое веб-приложение, ему нужна одна переменная.

Переменная | Значение | Зачем нужна?
-- | -- | --
INSTANCE_URL | Собирается из `PU_SECURE`, `PU_DOMAIN`, `PU_APP_PREFIX` и `PU_API_V1_PREFIX`, например `https://unit.example.com/pepeunit/api/v1/instances/current` | Адрес избранного инстанса клиента. Необязательная. Если пусто, избранного нет: инстанс выбирается через поиск инстансов

:::info
Задавать вручную не нужно: значение вычисляется из [файла настроек](/deployment/docker/deploy#файл-настроек). Кроме того, клиент знает несколько инстансов из коробки и показывает их в поиске инстансов, поэтому выбор не бывает пустым. Локальный инстанс добавляется формой «Добавить локально». Нативные приложения читают переменную, только если она задана при сборке, поэтому обычно избранного у них нет.

Из этой же переменной контейнер берёт публичный адрес клиента для превью ссылок (теги Open Graph): это адрес хоста из `INSTANCE_URL`, клиент считается открытым в корне хоста. Если переменная пуста, превью остаётся без `og:url`, а картинка берётся по относительному пути.
:::
