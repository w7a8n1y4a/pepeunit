# ClickHouse

:::info
В файл настроек эти переменные не пишутся: `make_env.py` берёт их из `PU_CLICKHOUSE_DATABASE_URL` и передаёт контейнеру `clickhouse`.
:::

Полный список переменных: [документация ClickHouse](https://clickhouse.com/docs).

Переменная | Откуда берётся | Зачем нужна?
-- | -- | --
CLICKHOUSE_USER | Имя пользователя из адреса | Имя пользователя базы данных
CLICKHOUSE_PASSWORD | Пароль из адреса | Пароль пользователя базы данных
CLICKHOUSE_DB | Имя базы из адреса, по умолчанию default | Название базы данных

:::warning
Значения применяются только при создании тома `clickhouse_data`. Позже их смена пароль в базе не меняет, см. [Файл настроек](/deployment/docker/deploy#файл-настроек).
:::
