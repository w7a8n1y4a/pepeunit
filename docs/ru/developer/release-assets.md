# Компиляция для различных платформ

Компилируемую программу нельзя просто распаковать из Git репозитория: её нужно собрать. Чтобы [Пользователю](/development-pepeunit/mechanics/roles#user) не приходилось собирать самому, готовые бинарные файлы прикладывают к релизам GitLab или GitHub.

К релизу можно приложить файлы с произвольными названиями. Такие пары название и ссылка называют assets. Pepeunit читает их через API GitLab и GitHub при каждой синхронизации Repo и сопоставляет релиз с Тегом.

На этой механике Pepeunit обновляет компилируемые Unit автоматически. Чтобы это работало, [Разработчик](/development-pepeunit/mechanics/roles#unit-developer) должен собрать программу под каждую платформу и приложить к каждому релизу, а название одной и той же платформы не менять от релиза к релизу.

## Как это работает в Pepeunit

1. Компилируемый Unit работает только с Тегами, коммит без Тега ему не подходит
1. При создании Unit выбирается платформа: это название asset
1. Найдя в релизе нужной версии asset с таким названием, Pepeunit отправит Unit ссылку на него в команде [UPDATE](/developer/mqtt/default-mqtt-command#update-update-pepeunit)
1. Если в релизе такого asset нет, Unit не создаётся и не обновляется

## Пример хорошего наименования assets между релизами
- Release 1.0.0: linux-amd64, macos
- Release 1.0.1: linux-amd64, esp8266-generic, macos
- Release 1.1.0: linux-amd64, esp8266-generic, macos
- Release 1.2.0: linux-amd64, esp8266-generic
- Release 1.3.0: linux-amd64, esp8266-generic, macos

Что произойдёт для каждой платформы:
- linux-amd64: Unit обновляется по всем версиям
- esp8266-generic: Unit можно создать начиная с версии 1.0.1, дальше обновления идут штатно
- macos: Unit обновляется до версии 1.1.0, на версии 1.2.0 обновление прервётся, а с версии 1.3.0 продолжится

## Пример плохого наименования assets между релизами
- Release 1.0.0: linux-amd64-1.0.0, macos-one
- Release 1.0.1: linux-amd64-1.0.1, esp8266-and-esp8266-generic, macos-two
- Release 1.1.0: linux-amd64-1.1.0, esp8266-generic, macos-three
- Release 1.2.0: linux-amd64-1.2.0, esp8266-and-esp8266-generic

Здесь названия меняются от релиза к релизу, поэтому автоматическое обновление не работает. Остаётся только ручное: платформу для каждой версии придётся выбирать вручную.
