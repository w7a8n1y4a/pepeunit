# readme.md

readme.md - документация Unit и самый важный файл репозитория: от его полноты зависит, насколько просто другим людям пользоваться Unit. Чтобы документация всех Unit выглядела одинаково, в клиенте есть генератор: он превращает [pepeunit.toml](/developer/files/struct-pepeunit-toml) в readme.md.

## Генерация readme.md

В клиенте откройте `Библиотека` → `Инструменты` → `Генератор README` и выберите pepeunit.toml, либо перетащите файл на соту. После этого README.md сохранится автоматически. Генератор доступен после входа в аккаунт.

Если в pepeunit.toml ошибка (превышен [предел](/developer/files/struct-pepeunit-toml#заполнение-general) или неверный синтаксис), генератор покажет её.
