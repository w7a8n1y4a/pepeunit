# readme.md

readme.md - документация Unit и самый важный файл репозитория: от его полноты зависит, насколько просто другим людям пользоваться Unit.

:::tip
Чтобы документация всех Unit выглядела одинаково, в клиенте есть генератор readme.md. Он превращает машиночитаемый [pepeunit.toml](/developer/files/struct-pepeunit-toml) в читаемый readme.md.
:::

## Генерация readme.md

:::info
В клиенте откройте `Библиотека` → `Инструменты` → `Генератор README` и выберите pepeunit.toml, либо перетащите файл на соту. После этого README.md сохранится автоматически. Генератор доступен после входа в аккаунт.
:::

Если в pepeunit.toml ошибка, генератор покажет её: слишком длинное поле, слишком много элементов в списке, файл больше 10000 символов или неверный синтаксис.
