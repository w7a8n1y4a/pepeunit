# Панели

`Dashboard` - страница [Grafana](/deployment/dependencies/grafana) с графиками данных ваших `UnitIO`. Раздел `Панели` доступен после входа, если на инстансе включён флаг `pu_ff_grafana_integration_enable`, см. [Настройки инстанса](/deployment/instance-settings#флаги). Панель видит только её создатель.

`DashboardPanel` - один график на панели. В клиенте он называется `Визуализация`.

Grafana рисует данные [DataPipe](/user/datapipe/datapipe): в визуализацию попадает только свой `UnitIO` с включённым и настроенным DataPipe.

## Создание

1. `Панели` → `Добавить панель`, введите имя: 4-20 символов, латинские буквы, цифры, `_`, `.`, `-`. Затем `Создать панель`
1. Откройте панель → `Визуализации` → `Добавить`. Введите название, выберите `Тип` (вид графика Grafana) и нажмите `Создать`
1. Откройте визуализацию → `Входы и выходы` → `Добавить`. Выберите `Unit` и его `UnitIO`, затем `Связать`
1. Вернитесь на панель и нажмите `Отправить в Grafana`
1. `Открыть в Grafana`

Флаги при `Связать`:

Флаг | Что значит
-- | --
`Только последнее` | Показывать только последнее значение, а не историю
`Значение как JSON` | Разбирать значение как JSON, для типов визуализации, которым это нужно

В одну визуализацию можно добавить не больше `UnitIO`, чем задано настройкой инстанса `pu_datapipe_limit_unit_io_per_one_panel`, по умолчанию `10`.

## Работа

Сота панели | Что делает
-- | --
`Информация` | Состояние синхронизации, версия Grafana, время последней отправки
`Отправить в Grafana` | Переносит панель и визуализации в Grafana. Нужна после каждого изменения: само оно не обновляется
`Открыть в Grafana` | Открывает панель. Пароль не нужен, вход выполняется через Pepeunit
`Удалить панель` | После подтверждения удаляет панель и её визуализации из Pepeunit

В визуализации: `Входы и выходы` ведёт к списку связанных `UnitIO`, нажатие на `UnitIO` убирает его из визуализации. Сам `UnitIO` и данные остаются. `Удалить` убирает визуализацию.
