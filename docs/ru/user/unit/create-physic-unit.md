# Запуск Unit на устройстве

Созданный [Unit](/user/unit/create-unit) нужно один раз вручную перенести на устройство. Дальше он обновляется сам: [Система обновлений](/development-pepeunit/mechanics/update-system).

## Переменные окружения

`Аппараты` → `Unit` → `Переменные окружения`. Сота есть только у создателя `Unit`. Откроется редактор `env.json`.

Обычно [Разработчик Unit](/development-pepeunit/mechanics/roles#unit-developer) уже настроил переменные, но часть нужно заполнить своими данными, например `WIFI_SSID` и `WIFI_PASS`. Что значит каждая переменная, написано в README репозитория: ссылка на него в `Сводка` у `Repo`.

Кнопка | Что делает
-- | --
`Сохранить` | Записывает переменные на инстанс [шифрованными](/development-pepeunit/mechanics/cipher)
`Сброс` | Удаляет сохранённые переменные: останется то, что вернёт [алгоритм генерации env.json](/development-pepeunit/mechanics/alg-env)

:::warning
Ключи из [env_example.json](/developer/files/struct-env-example-json) удалять нельзя: с отсутствующей переменной `Сохранить` вернёт ошибку.
:::

:::danger
Пока вы не нажали `Сохранить`, `PU_SECRET_KEY` и `PU_ENCRYPT_KEY` создаются заново при каждой выдаче `env.json`: архив и следующее `Обновить окружение` дадут разные ключи. Нажмите `Сохранить` до скачивания файлов, даже если ничего не меняли.
:::

## Файлы для устройства

`Аппараты` → `Unit` → `Управление аппаратом`. В зависимости от типа программы набор файлов разный.

### Интерпретируемый Unit

`Архивы программ` → `ZIP`, `TAR` или `TGZ`. В архиве вся программа, `env.json` и `schema.json`.

### Компилируемый Unit

Нужны два набора файлов:

1. `Платформы` → ссылка на сборку для вашей платформы, см. [Компиляция для разных платформ](/developer/release-assets). Сота есть только у компилируемых `Unit`
1. `Архивы программ` → архив. В нём только `env.json` и `schema.json`

Положите файлы из архива рядом со сборкой, чтобы программа их видела. Подробнее: [Структура архивов](/developer/files/struct-archive-update).

## Первый запуск

Загрузите файлы на устройство и запустите его.

- Микроконтроллеры (`esp32`, `stm`): файлы в `flash`, запуск кнопкой `reset`
- `Micropython`: сначала на устройство ставится интерпретатор
- Программы для компьютера: запуск бинарного файла или командой интерпретатора

:::warning
Единого правила нет: `Unit` бывают разными. Порядок запуска описывает README репозитория.
:::

Когда `Unit` вышел на связь, в `Unit` → `Информация` появятся его состояние и версия, а в `Управление аппаратом` → `Логи` его сообщения. Если не появилось, см. [Управление Unit](/user/unit/manage).
