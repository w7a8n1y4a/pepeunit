# Создание Unit

`Unit` - устройство или программа, созданная из [Repo](/user/repo). У него своя версия, окружение и токен. Для создания нужен вход в аккаунт и хотя бы один `Repo`.

`Аппараты` → `Создать аппарат`. Либо `Репозитории` → `Repo` → `Создать аппарат`: тогда `Repo` уже выбран.

Сота | Что задать
-- | --
`Выбрать репозиторий` | `Repo`, из которого создаётся `Unit`. Список ищется по адресу
`Имя` | От 4 до 20 символов: латинские буквы, цифры, `_`, `.`, `-`
`Видимость` | `Публичный`, `Внутренний` или `Приватный`, по умолчанию `Внутренний`. См. [Видимость](/development-pepeunit/mechanics/visibility)
`Ветка` | Ветка `Repo`, из которой берётся программа
`Обновления` | Тип программы, режим обновления, коммит и платформа
`Создать` | Создаёт `Unit`

## Обновления

В `Обновления` выбирается:

- Тип программы: `Компилируемый` или `Интерпретируемый`. Компилируемому нужна `Платформа`
- Режим: `Автообновление` или `Руками`. С `Руками` нужно выбрать `Коммит`
- Для автообновления: брать последний коммит ветки или только коммиты с тегом. У компилируемого `Unit` берутся только теги

По умолчанию: интерпретируемый, автообновление, только теги. Как выбирается версия и когда `Unit` обновляется: [Система обновлений](/development-pepeunit/mechanics/update-system). Всё это можно изменить позже в `Настройки` `Unit`.

## После создания

`Unit` создан, но ещё не работает: ему нужны переменные окружения и запуск на устройстве, см. [Запуск Unit на устройстве](/user/unit/create-physic-unit).

Pepeunit сам создаёт `UnitIO` - входы и выходы по `schema_example.json` версии, см. [Входы и выходы](/user/unit/io).
