# Группы Unit

`UnitGroup` собирает несколько `Unit` вместе для удобства. На видимость и доступ группа не влияет, а видит её только создатель. Один `Unit` может состоять в нескольких группах.

`Аппараты` → `Группы`: список групп с поиском по названию.

Сота | Что делает
-- | --
`Создать группу` | Вводится название, затем `Создать группу`
`Имя` | Меняет название группы
`Иконка` | Выбор значка группы
`Состав` | `Unit` группы. `Добавить` открывает выбор `Unit`
`Удалить` | Удаляет группу, `Unit` остаются на инстансе

Нажатие на `Unit` в составе группы даёт выбор: `Открыть` его меню или `Убрать` из группы. Сам `Unit` при этом не удаляется.
