# Репозитории

`Repo` - копия Git репозитория с программой для `Unit`. Лежит на инстансе, живёт на `GitLab` или `GitHub`. Как подготовить такой репозиторий: [Алгоритм создания Unit](/developer/alg-create-unit). Публичные `Repo` других инстансов появляются сами, см. [Федерацию](/development-pepeunit/mechanics/federation).

## Добавить

`Репозитории` → `Добавить репозиторий`:

Сота | Что вводить
-- | --
`Ссылка` | `http(s)` ссылка, заканчивающаяся на `.git`
`Платформа` | `Гитхаб` или `Гитлаб`
`Публичный` / `Приватный` | Нажатие переключает вид доступа
`Креды` | Для приватного `Repo`: имя пользователя и токен доступа

Затем `Добавить`. Токен хранится на инстансе [шифрованным](/development-pepeunit/mechanics/cipher).

## Приватный Repo

Приватный `Repo` виден в списке всем вошедшим, но синхронизировать его и создавать из него `Unit` можно только со своими кредами. Откройте `Repo` → `Креды` и введите своё имя и токен. Сота есть только у приватных `Repo`. См. [Видимость](/development-pepeunit/mechanics/visibility).

## Карточка Repo

`Репозитории` → `Поиск`: строка поиска по адресу и фильтр по виду доступа. Карточка показывает вид доступа, размер и число `Unit`.

Сота | Что делает
-- | --
`Сводка` | Ветки, коммиты и другие сведения. Значок копирует ссылку
`Создать аппарат` | Открывает [создание Unit](/user/unit/create-unit) из этого `Repo`
`Синхронизировать репо` | Обновляет локальную копию из Git
`Креды` | Свои имя и токен, для приватного `Repo`
`Ветки` | Список веток
`Удалить` | Только создатель и только если у `Repo` нет `Unit`

Если новой ветки или коммита нет в списке, нажмите `Синхронизировать репо`: статус синхронизации виден на соте. Сам `Repo` обновляется каждый час в `:30`, см. [Систему обновлений](/development-pepeunit/mechanics/update-system#обновление-repo).
