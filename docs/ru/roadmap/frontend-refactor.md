# Рефактор фронтенда в клиент

Клиент — Flutter-приложение в этом репозитории (`pepeunit_client`). Старые фронтенды уходят в архив; документация живёт рядом с клиентом.

Именование ниже согласовано с кодом (`lib/navigation/sections.dart`, `lib/hive/hex_scene.dart`, `lib/main.dart`). Расхождения со старыми черновиками намеренны.

## Стек

- Flutter
- UI: свой сотовый слой (`lib/hive`), не shadcn
- Платформы: web, linux, macos, windows, android, ios
- Роутинг: `go_router`, path URL strategy
- Иконки: SVG (`flutter_svg`, `assets/icons/`)
- Хранилище аккаунта: `flutter_secure_storage` + `shared_preferences` (`PlatformVaultStore`)
- API: ручной `PepeunitApi` → цель — генерация типов и ручек из `openapi.json` бекенда

### Код

- DRY, SOLID/DDD по мере роста модулей (`account/`, `instances/`, `hive/`, `features/`)
- Типизация Dart
- Полный охват пользовательских ручек OpenAPI; исключения: Grafana datasource, Telegram-обвязка, Prometheus и прочий сервисный слой
- Роли (`Owner` / `Admin` / …) и флаги инстанса влияют на доступные действия и пункты меню
- Кеш картинок (аватары/иконки инстансов) — довести до явной политики

### Совместимость бекенда

`lib/api/backend_version.dart`: допустимы версии `1.5.x` (`major == 1 && minor >= 5 && minor < 6`).

### Feature flags

Читаются из портрета инстанса (`pu_ff_*`). Сейчас на главном меню:

- без target доступны только `people`, `peers`, `library`
- `alerts` скрывается при `pu_ff_notification_enable == false`
- `dashboards` скрывается при `pu_ff_grafana_integration_enable == false`

## Сотовый UI

Все экраны — **pointy-top** шестигранники (угол сверху/снизу). Рендер общий для платформ; меняется только ввод (мышь / тач / жесты).

### Анатомия соты меню

1. Цветной бордер (акцент раздела; у «Назад» — `hexMuted`)
2. Подпись по верхней левой грани (длинный текст ≥13 символов — дуга по обеим верхним граням)
3. Иконка SVG или PNG-аватар в центре
4. Опционально подписи по нижним граням (`footer` / `footerLeft`)
5. План: бейдж уведомлений на правой верхней грани (красный + число)

Реализация: `HexSlot` / `HexPainter` в `lib/hive/hex_scene.dart`.

### Сетка и размеры

- Осевые координаты `(q, r)`, шаг и fit-to-screen в `HexLayout`
- Зазор между бордерами пропорционален размеру соты; из стандартных / уменьшенных / увеличенных собирается ровная сетка
- Типоразмеры: стандарт, уменьшенный, увеличенный, кастомный множитель
- Соты могут менять размер при переходах и подгонке под экран

### Центрирование

Интерфейс по центру экрана, максимум площади при адекватных отступах:

- меню «1 + 6» — центр = центр центральной соты
- ряды (напр. 3–4–3) — геометрический центр кластера
- произвольная раскладка — bbox + геометрический центр
- карточка данных — якорь по главному гексагону
- форма ввода — по центру; при переполнении по вертикали — скролл

Отступы от соотношения сторон (16:9 → ведущие верх/низ; узкий портрет → ведущие бока), без нарушения правила «максимум экрана».

### Адаптивность

От размера экрана: подписи, иконка↔текст, размеры сот/иконок, число видимых сот.  
От платформы: только управление.  
От aspect ratio: отступы.

### Масштаб (`scope`)

Ступенчатый zoom (колёсико / pinch), только если есть что добавить в рендер. В «статичных» формах масштаб выключен.

Сейчас реализовано для сети: query `?scope=0|1|2` (`ScopeFrame` / `scopeOf`), кольца `hexDisk`.  
План для главного меню: слой 1 — по 2 дочерние соты на каждую из 6 внешних (12 слотов, «диафрагма»); слой 2+ — наращивание колец по приоритету пунктов внутренних меню.

## Навигация

- Клик по соте → новый экран (меню, карточка, форма…)
- **Назад** — `back.svg`, бордер `hexMuted`
  - на корне главного меню нет
  - в глубине иерархии меню — в центре
  - на промежуточных меню — правое нижнее
  - в прочих интерфейсах — по месту
- **К родителю сущности** (план) — цепочка UnitIO → Unit → Repo; иконка в духе `house.svg` / прицел (`sight.svg` уже есть для target)
- Web: меню и сущности в URL; `scope` в query при передаче ссылок
- План deep links: unit, repo, UnitIO

Меню — дерево глубины (до 6 сот на уровень), не самоцель: рано или поздно выводит на контент. Может быть встроено в экран.

### Типы экранов

Инфокарточка · поиск · форма · клавиатура кнопок · редактор yml · Grafana kiosk · графики · комбинированные · кастомные (в той же сотовой стилистике).

## Аккаунт и вход

Реализовано (`/people`, `/people/login|register|settings`):

- регистрация / вход по ключу, выход, скачивание ключа
- настройки: логин, аватар, sync профиля в сеть, язык, UTC-пояс
- vault глобального аккаунта + сессии инстансов
- сота ошибки с копированием текста (`ErrorCell`)

Сеть / инстансы (реализовано в `/peers/…`):

- портрет текущего инстанса, список известных, поиск, allow/deny, ручное добавление
- карточка инстанса: target, relogin, метрики, настройки owner и т.д. по ролям и ff
- `scope` для плотности сетки пиров

План:

- «войти во все» с кулдауном
- дефолтный топ-10 инстансов в бинарниках
- ссылка на docs из клиента
- система обновлений клиента/сервера (см. ниже)

## Комбинированные интерфейсы

Эталон сложности — карточка Unit. Старый фронт вываливал всё сразу (версии, RAM/flash/сеть, env, архивы, бинарники, MQTT, логи, опции, удаление) — антипаттерн.

Принцип: скрыть / вынести в подменю / переразместить; визуально — соты разного калибра, лёгкая асимметрия для иерархии.

Идеи:

- MQTT: одна кнопка → диагональная панель из 6 сот (5 команд + назад), лёгкое затемнение фона
- ошибки: иконка черепа pepe (`error.svg` уже в духе pepe)
- key–value «ёлочкой»: key ~−135° к левой нормали, value ~−45° к правой — протестировать

## Фон

Монотонная база (`sceneBackground`); оттенок по месяцу / праздничные варианты — план.

Поверх — мозаика белых SVG (MIT / сгенерированные, без чужого копирайта): поворот ±20°, «шелест», редкий flip с заменой.

Все иконки приглушены, создавая фон, но не бросаясь в галаза

Темы (каталог ассетов):

- Pepe
- Растения: клён, каннабис, дерево, цветок в горшке, кактус, лейка, арбуз, гриб
- Животные: хамелеон, пчела, мамонт, кит, собака, кот, кальмар, краб, вальдшнеп, корова
- Символы: мир, SPQR, инь-ян, пятиконечная звезда, череп, сердце, щит, книга, медицина
- Математика: ∅, ∞, F(x), Σ, ∫, тождество Эйлера, π
- Физика: E=mc², F=ma
- Поп: Hidden Leaf, sus
- Технологии: wifi, ble, esp, АК, ракета
- Религии: христианство, ислам, народные верования Китая, индуизм, буддизм
- Валюты: ETH, BTC, CNY, USD, INR, RUB, JPY, EUR
- Славянские: коловрат, восьмиконечная звезда, топор Перуна, Мокошь, Михаил и змей
- Египет: анкх, око Гора, Анубис, скарабей, джед
- Азия: 道 力 天 心 和
- Стихии: огонь, вода, воздух, снежинка, земля, молния, атом

## Анимация

Интерфейс отзывчивый:

- эффекты нажатия (искры, ветер, снег, молнии, лучи…)
- переходы между экранами/сотами
- ошибка: читаемый текст + копирование (копирование есть; «бегущая строка» — опционально)
- hover соты: лёгкий scale или ярче бордер

## Дальнейшие разделы

### Units / Registry / Dashboards / Alerts

Пока `PlaceholderPage`. Полный функционал pepeunit через OpenAPI; карточка Unit — по правилам комбинированных интерфейсов выше.

### Library

Документация-дерево; миниигры (хотя бы микро-казино на фейк-койнах).

### System design

На базе `group` бекенда: схема из Unit и связей; раскладка на клиенте; пустые ячейки под юниты.

### UX

Клиент должен оставаться понятным среднему пользователю: меню ведёт к действию, а не к бесконечной навигации.
