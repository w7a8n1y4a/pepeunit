# Рефактор фронтенда в клиент

Клиент — Flutter-приложение в этом репозитории. Сделанное и ограничения UI лежат в коде и в `.cursor/rules/` (`client.mdc`, `hive-ui.mdc`, `hex-layout.mdc`). Раскладка сот записана здесь и в `hex-layout.mdc`. Остальное в этом файле — план и решения, которых в правилах нет.

Именование согласовано с кодом (`lib/navigation/sections.dart`, `lib/hive/hex_scene.dart`, `lib/main.dart`). Расхождения со старыми черновиками намеренны.

- `dashboards` скрывается при `pu_ff_grafana_integration_enable == false`

## Позиция соты

Позиция — два числа: номер круга и угол. Угол меряется от центральной соты: 0° вправо, 90° вверх, против часовой стрелки. Так проще, чем сверять соты по граням.

Круг 0 — центральная сота. Круг N — периметр толщиной в одну соту, в нём `6N` сот. Шаг угла `360 / (6N)` градусов.

- 1 круг, шаг 60°: 0, 60, 120, 180, 240, 300
- 2 круг, шаг 30°: углы 1 круга и 30, 90, 150, 210, 270, 330
- 3 круг, шаг 20°: углы кратные 20°
- 4 круг — 24 соты, шаг 15°; 5 круг — 30 сот, шаг 12°

В коде слот пишется осевыми `(q, r)` и рисуется решёткой `HexLayout`. Круги 1 и 2 попадают в эти углы точно. С 3 круга адрес — ячейка решётки этого круга, ближайшая к номинальному углу. Кольцо не выкладывается на одну окружность равного радиуса.

1 круг, `(q, r)`: 0° `(1, 0)`, 60° `(1, -1)`, 120° `(0, -1)`, 180° `(-1, 0)`, 240° `(-1, 1)`, 300° `(0, 1)`.

Одна сота стоит в центре экрана. Кластер больше одной соты центрируется по центральной.

## Порядок появления

1. Первой появляется центральная сота.
2. Следующий круг начинается, когда заполнен предыдущий.
3. Позиции home задаёт `menuSections`. Этот порядок — для набора сот переменной длины.

Вертикальный экран (`ширина <= высота`; квадрат тоже вертикальный). В каждом круге:

1. Верх: от 120° к 60° включительно. Верхняя строка заполняется без боковых сот, ширина кластера не растёт.
2. Низ: от 300° к 240° включительно.
3. Левая сторона: от 120° к 240°, концы не входят, угол растёт.
4. Правая сторона: от 60° к 300° короткой дугой через 0°, концы не входят.

Горизонтальный экран (`ширина > высота`): те же дуги, другой порядок — левая сторона, правая, верх, низ. Сначала растёт ширина, потом высота.

## Меню

- В меню не больше 7 сот, если тики масштаба не оговаривают иное.
- Восьмая сота допустима только как ошибка и занимает следующий свободный слот.
- «Назад» на промежуточном слое — 1 круг, 300°. На последнем слое — центр. Этот слот занят, остальные соты идут по порядку появления в свободные места.
- На корне home «Назад» нет. Вне меню «Назад» стоит по месту экрана.

### Поверх раскладки

- Бейдж уведомлений на правой верхней грани (красный + число) — план
- Соты могут менять размер при переходах и подгонке под экран
- Карточка данных — якорь по главному гексагону
- Отступы: 16:9 — ведущие верх/низ; узкий портрет — ведущие бока

### Масштаб главного меню

Тики масштаба могут вывести меню за 7 сот. Слой 1 — по 2 дочерние соты на каждую из 6 внешних (12 слотов, «диафрагма»). Слой 2+ — наращивание колец по приоритету пунктов внутренних меню. Состав дочерних сот — открытый вопрос, по разделу.

Поведение на home, которого нет в `menuSections`:

- при логине центральная сота показывает логин + отпечаток ключа / аватар
- при выбранном target сота Сети показывает хост, версию, «Текущий», иконку инстанса

## Навигация

- **К родителю сущности** (план) — цепочка UnitIO → Unit → Repo; иконка в духе `house.svg` / прицел (`sight.svg` уже есть для target)
- Web: меню и сущности в URL; `scope` в query при передаче ссылок
- План deep links: unit, repo, UnitIO

Меню — дерево, которое выводит к действию. Может быть встроено в экран.

### Типы экранов

Инфокарточка · поиск · форма · клавиатура кнопок · редактор yml · Grafana kiosk · графики · комбинированные · кастомные (в той же сотовой стилистике).

## Аккаунт и сеть

Реализовано (`/people`, `/people/login|register|settings`):

- регистрация / вход по ключу, выход, скачивание ключа
- настройки: логин, аватар, sync профиля в сеть, язык, UTC-пояс
- vault глобального аккаунта + сессии инстансов
- сота ошибки с копированием текста (`ErrorCell`)

Сеть / инстансы (`/peers/…`):

- портрет текущего инстанса, список известных, поиск, allow/deny, ручное добавление
- карточка инстанса: target, relogin, метрики, настройки owner и т.д. по ролям и ff

План:

- «войти во все» с кулдауном
- дефолтный топ-10 инстансов в бинарниках
- ссылка на docs из клиента
- система обновлений клиента/сервера (см. ниже)

## Комбинированные интерфейсы

Эталон сложности — карточка Unit. Старый фронт вываливал всё сразу (версии, RAM/flash/сеть, env, архивы, бинарники, MQTT, логи, опции, удаление) — антипаттерн. Лёгкая асимметрия сот показывает иерархию.

Идеи:

- MQTT: одна кнопка → диагональная панель из 6 сот (5 команд + назад), лёгкое затемнение фона
- ошибки: иконка черепа pepe (`error.svg` уже в духе pepe)
- key–value «ёлочкой»: key ~−135° к левой нормали, value ~−45° к правой — протестировать

## Фон

Монотонная база (`sceneBackground`); оттенок по месяцу / праздничные варианты — план.

Поверх — мозаика белых SVG (MIT / сгенерированные, без чужого копирайта): поворот ±20°, «шелест», редкий flip с заменой.

Все иконки приглушены, создавая фон, но не бросаясь в галаза

Темы (каталог ассетов):

- Pepe
- Растения: клён, каннабис, дерево, цветок в горшке, кактус, лейка, арбуз, гриб
- Животные: хамелеон, пчела, мамонт, кит, собака, кот, кальмар, краб, вальдшнеп, корова
- Символы: мир, SPQR, инь-ян, пятиконечная звезда, череп, сердце, щит, книга, медицина
- Математика: ∅, ∞, F(x), Σ, ∫, тождество Эйлера, π
- Физика: E=mc², F=ma
- Поп: Hidden Leaf, sus
- Технологии: wifi, ble, esp, АК, ракета
- Религии: христианство, ислам, народные верования Китая, индуизм, буддизм
- Валюты: ETH, BTC, CNY, USD, INR, RUB, JPY, EUR
- Славянские: коловрат, восьмиконечная звезда, топор Перуна, Мокошь, Михаил и змей
- Египет: анкх, око Гора, Анубис, скарабей, джед
- Азия: 道 力 天 心 和
- Стихии: огонь, вода, воздух, снежинка, земля, молния, атом

## Анимация

- эффекты нажатия (искры, ветер, снег, молнии, лучи…)
- переходы между экранами/сотами
- ошибка: читаемый текст + копирование (копирование есть; «бегущая строка» — опционально)
- hover соты: лёгкий scale или ярче бордер
